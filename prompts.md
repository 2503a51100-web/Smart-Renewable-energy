# AI-Assisted Coding – Prompt Engineering

## Project: AI-Assisted Smart Renewable Energy Monitoring Platform

### 1. Project Planning Prompt

Create a full-stack renewable energy monitoring application that monitors solar and wind energy production using simulated data. Use HTML, CSS, JavaScript, Python FastAPI and SQLite.

### 2. Frontend Development Prompt

Create a modern, responsive renewable energy monitoring dashboard using HTML, CSS and JavaScript. Include energy generation cards, solar and wind statistics, energy consumption charts, device status and alerts. Use Chart.js for interactive graphs.

### 3. Backend Development Prompt

Develop a Python FastAPI backend for the renewable energy monitoring application. Create REST APIs to retrieve energy records, add devices, calculate energy statistics and generate alerts. Write clean, modular and maintainable code.

### 4. Database Development Prompt

Create an SQLite database for the renewable energy monitoring application. Include users, devices, energy_records and alerts tables with appropriate primary keys, foreign keys and constraints.

### 5. Data Analytics Prompt

Use Pandas to analyze solar and wind energy production data. Calculate total generation, average production, daily production and monthly production.

### 6. AI Insights Prompt

Develop an energy anomaly detection feature that identifies unusually low or high energy production compared with historical records. Generate understandable recommendations based on detected patterns.

### 7. Testing Prompt

Generate test cases for the FastAPI endpoints. Test valid inputs, invalid inputs, database operations and error handling. Use pytest.

### 8. Debugging Prompt

Review the provided code, identify syntax errors, logical errors and runtime issues. Explain the problems and provide corrected code without changing the existing application requirements.

### 9. Documentation Prompt

Generate clear technical documentation explaining the application modules, REST APIs, database structure, installation steps and execution process.

### 10. Code Review and Security Prompt

Review the application for code quality, security vulnerabilities, input validation and performance issues. Suggest improvements following Python and web development best practices.
